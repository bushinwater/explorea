## Instalacija .NET SDK

Preuzmite i instalirajte najnoviji .NET SDK (LTS verzija) sa zvanične stranice:

[https://dotnet.microsoft.com/download](https://dotnet.microsoft.com/download)

---

### Windows

Pokrenite preuzeti `.exe` installer i pratite korake. Nakon instalacije, restartujte terminal.

```powershell
# Alternativno, putem winget-a
winget install Microsoft.DotNet.SDK.10
```

---

### macOS

```bash
# Putem Homebrew
brew install --cask dotnet-sdk
```

> Na Apple Silicon (M1/M2/M3) obavezno preuzmite **Arm64** verziju sa sajta.

---

### Linux (Ubuntu / Debian)

```bash
# 1. Dodaj Microsoft repozitorijum
wget https://packages.microsoft.com/config/ubuntu/22.04/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb

# 2. Ažuriraj i instaliraj SDK
sudo apt-get update
sudo apt-get install -y dotnet-sdk-10.0
```

---

## Verifikacija instalacije

```bash
# Provera verzije SDK-a
dotnet --version

# Prikaz svih instaliranih SDK-ova i runtime-ova
dotnet --info
```

Očekivani izlaz `dotnet --version`:

```
10.0.xxx
```

## Podešavanje IDE-a

### Visual Studio Code

Preuzmite VS Code sa [https://code.visualstudio.com](https://code.visualstudio.com), a zatim instalirajte sledeće ekstenzije:

| Ekstenzija        | Svrha                                          |
| ----------------- | ---------------------------------------------- |
| C# Dev Kit        | Osnovna podrška za C# razvoj                   |
| C#                | IntelliSense i debugovanje                     |
| .NET Install Tool | Upravljanje .NET runtime-ovima                 |
| REST Client       | Testiranje API endpointa direktno iz VS Code-a |

```bash
# Instalacija putem terminala
code --install-extension ms-dotnettools.csdevkit
code --install-extension ms-dotnettools.csharp
code --install-extension ms-dotnettools.vscode-dotnet-runtime
code --install-extension humao.rest-client
```

## Instalacija EF Core CLI alata

Entity Framework Core CLI alat se koristi za rad sa migracijama baze podataka.

```bash
# Instaliraj globalno
dotnet tool install --global dotnet-ef

# Verifikacija
dotnet ef --version
```

### EF Core NuGet paketi po bazi podataka

U zavisnosti od izabrane baze podataka, u projekat je potrebno dodati odgovarajući paket:

PostgreSQL `Npgsql.EntityFrameworkCore.PostgreSQL`

```bash
# Primer za PostgreSQL
dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL


```

## Provera okruženja

Pokrenite sve komande i proverite da li su izlazi ispravni:

```bash
# .NET SDK
dotnet --version          #  10.0.xxx

# Svi instalirani SDK-ovi
dotnet --list-sdks

# EF Core CLI
dotnet ef --version       #  Entity Framework Core ...

# Globalni alati
dotnet tool list --global
```
